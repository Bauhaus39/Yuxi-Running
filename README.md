# 玉玺快跑 · 雪夜皇城大逃亡

一个用 Canvas 写的三车道无尽跑酷小游戏。抱着传国玉玺，在雪夜皇城里一路狂奔，别被“高松灯企鹅”追上。

## 打开方式

- **推荐**：双击根目录的 `玉玺快跑.html`（单文件版，图片和代码都已内嵌，不需要联网）。
- 开发版：用浏览器打开本目录的 `index.html`（需要保留 `assets/game` 文件夹）。

## 操作

| 操作 | 键盘 | 手机 |
| --- | --- | --- |
| 左右变道 | ← / → 或 A / D | 左右滑动，或左下角按钮 |
| 跳跃 | ↑ / W / 空格 | 上滑，或右下角「跳」 |
| 滑铲 | ↓ / S | 下滑，或右下角「滑」 |
| 暂停 | P / Esc | 右上角暂停按钮 |
| 静音 | M | 右上角声音按钮 |

## 玩法

- 收集玉玺：增加追捕距离，并累积连击倍率。
- 撞上障碍：被追近 9 米，连击清零。
- 追捕距离归零：被企鹅灯抓住，游戏结束。
- 龙鳞护盾可以抵挡一次撞击；聚玉符会在 8 秒内自动收集玉玺。
- 追捕距离越短，企鹅灯会靠得越近；危险时画面边缘会变红。

## 素材与说明

- 逃跑者：使用用户提供的头像照片，裁切后与手绘身体合成。
- 追捕者：高松灯企鹅网络表情包，来自 [求表情网的高松灯企鹅表情包合集](https://www.qiubiaoqing.com/album/user_album/878014315314020994.html)。这里只做了裁切、透明化与动画帧整理，仅作个人娱乐，非商业用途。
- 背景、角色身体、障碍、UI 均为 Canvas / CSS 绘制；音效由 WebAudio 实时合成，无外部依赖。

## 文件

- `index.html` / `style.css` / `game.js`：可读源码。
- `assets/game/`：游戏内使用的图片。
- `build_standalone.py`：将开发版打包成单文件 HTML。
